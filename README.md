## История версий

- **v65** — добавлены USDCHF и USDJPY; для пар, где доллар стоит первым, результат переводится в доллары; BRENT переведён на 3 знака.
- **v64** — добавлены GBPUSD и US500 (S&P 500); WTI переведён на 3 знака после запятой.
- **v63** — блок «ЧЕК-ЛИСТ»: 15 факторов перед входом, отдельная таблица `ENTRY_FACTORS` в экспорте. Только статистика, на расчёты не влияет.
- **v62** — точный расчёт PnL при выходе в безубыток.
- **v61** — автоматическое распределение риска между входами.
- **v60** — раздельные балансы Real и Backtest.
